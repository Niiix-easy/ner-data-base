# Enterprise

## SLA
`uptimeTargetBps=9999` representa 99,99%.

## Custom pricing
Suporta FIXED, DISCOUNT, TIERED e COMMITMENT.

## Custom contracts
Contratos têm período, renovação, moeda e observações.

## Dedicated infrastructure
Registra região, provedor, cluster, rede, capacidade e nível de isolamento.
O provisionamento real deve ser feito por um controller/operator seguro; esta API registra o desired state e não executa infraestrutura diretamente.
